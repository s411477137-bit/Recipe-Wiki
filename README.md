# Recipe Wiki｜美食料理知識百科

奶油色系、簡約溫暖的料理入門知識庫與互動式 HTML 教學簡報。

## 快速開始
1. 解壓縮專案。
2. 直接以瀏覽器開啟 `index.html`。
3. 使用「上一頁／下一頁」或鍵盤左右方向鍵切換。
4. Wiki 文章位於 `wiki/`；來源清單位於 `sources.csv`。

## 專案結構
- `index.html`：教學型 HTML 簡報（單檔、無需安裝套件）
- `wiki/`：6 篇 Wiki 知識文章
- `sources.csv`：來源清單及 Wiki 對應
- `workflow.md`：Loop / Graph 流程與節點說明
- `作業報告.md`：成果、執行紀錄與反思
- `README.md`：本說明

## GitHub Pages 部署
1. 在 GitHub 建立新的 Public repository，例如 `recipe-wiki`.
2. 將本資料夾所有檔案上傳到 repository 根目錄。
3. 進入 **Settings → Pages**。
4. 在 **Build and deployment** 選擇 **Deploy from a branch**。
5. Branch 選 `main`，資料夾選 `/ (root)`，按 Save。
6. 等待部署完成，網址通常為 `https://你的帳號.github.io/recipe-wiki/`。
7. 開啟網址確認首頁、導覽與互動測驗正常。
